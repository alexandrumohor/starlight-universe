How to use

  1. Click Download PNG on each icon above
  2. Save the 3 PNGs to:
    resourcepack/assets/starlight/textures/font/
  3. Files should be named: money_icon.png, gems_icon.png, stars_icon.png
  4. The font definition is already at assets/minecraft/font/default.json
